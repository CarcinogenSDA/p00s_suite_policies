p00s Suite — Privacy Policy

Last updated: October 2026

p00s Suite is a personal livestream-management tool built and operated by a single individual (the "owner") for their own private use. It is not a commercial product, it is not distributed to the public, and it has exactly one user: the owner themselves.

What this app does

p00s Suite runs on the owner's own computer and helps manage their own Twitch and YouTube livestreams — things like on-screen donation goal bars, chat overlays, alerts, and updating the title, description, tags, and thumbnail of the owner's own live broadcasts.

Google / YouTube data

p00s Suite connects to the YouTube Data API using Google OAuth, authorized exclusively by the owner's own Google account, to:

  • Read and update the title, description, and tags of the owner's own YouTube videos and live broadcasts
  • Set a custom thumbnail image on the owner's own YouTube videos
  • List the owner's own channel's active and upcoming live broadcasts
  • Post chat messages to the owner's own live chat, as the owner

This data is used only to display it back to the owner inside their own locally-running admin panel, or to send the owner's own requested updates back to YouTube on their behalf. It is stored only on the owner's own computer (never on a third-party server), is never sold, shared, transmitted to any third party, or used for advertising, analytics, or any purpose other than operating this single-user tool for its owner.

Other integrations

p00s Suite may also connect to Twitch, Patreon, and/or Ko-fi using similar OAuth grants, again authorized only by the owner's own accounts on those services, and again used only to operate the owner's own stream tooling for themselves. The same handling described above applies: data stays local, is never shared or sold.

Data retention and deletion

All data is stored locally on the owner's own machine. Revoking this app's access from your Google Account's third-party access settings immediately stops any further access; deleting the local application data removes everything else.

Contact

This is a personal, single-user tool with no public support channel. Questions about this policy can be directed to the repository this page is published from.
